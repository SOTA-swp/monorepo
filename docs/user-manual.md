# Trippy ユーザーマニュアル

## 本書の目的と対象読者

### 本書の目的

本書は、旅行計画作成・共有サービス「Trippy」の使用方法を詳細に解説するユーザーマニュアルです。Trippyのすべての機能を理解し、効果的に活用することで、思い出に残る旅行計画を作成・管理できるようになることを目的としています。

### 対象読者

- **初めてTrippyを使用するユーザー**: アカウント作成から基本的な計画の作成方法まで、ステップバイステップで学べます
- **既存ユーザー**: より高度な機能（共同編集、ルート計算、エクスポート機能など）を活用したい方
- **旅行計画を他者と共有したいユーザー**: チームでの旅行計画を効率的に管理したい方
- **過去の旅行を記録・整理したいユーザー**: 旅行の思い出を整理し、他のユーザーと共有したい方

## 1. はじめに

### 1.1 Trippyとは

Trippyは、旅行計画の作成、管理、共有を行うことができるWebアプリケーションです。

**主な特徴:**

- 📅 **タイムライン管理**: 旅行スケジュールを時系列で視覚的に管理
- 🗺️ **マップ統合**: Google Mapsと連携して場所を視覚化
- 💡 **アイデアスペース**: 行きたい場所をカードで整理
- 👥 **共同編集**: 友人や家族と一緒に計画を作成
- 🔍 **検索機能**: 他のユーザーの公開計画を参考にできる
- ❤️ **お気に入り**: 気に入った計画をいいねして保存
- 🔒 **プライバシー管理**: 公開・非公開を自由に設定

### 1.2 推奨環境

**対応ブラウザ:**

- Google Chrome
- Microsoft Edge

**推奨画面解像度:**

- デスクトップ: 1920×1080以上
- タブレット: 1024×768以上

**インターネット接続:**

- 常時接続が必要（マップ表示、データ同期のため）

### 1.3 利用開始前の準備

1. **インターネット接続の確認**
2. **対応ブラウザのインストール**
3. **Googleアカウント**: 現時点ではGoogle認証に対応予定（メール/パスワード認証も利用可能）

## 2. アカウント管理

### 2.1 新規アカウント作成

#### 手順

1. **トップページにアクセス**
   - ブラウザでTrippyのトップページを開きます
   - 右上の「新規登録」ボタンをクリックします

2. **登録情報の入力**
   - **ユーザー名**: 1文字以上50文字以下で入力
   - **メールアドレス**: 有効なメールアドレスを入力
   - **パスワード**: セキュリティを考慮した強固なパスワードを設定

3. **アカウント作成の完了**
   - 「アカウント作成」ボタンをクリック
   - 登録が成功すると、マイページに自動的に遷移します

#### 注意事項

- ユーザー名は後から変更可能です
- メールアドレスは必ず確認可能なものを使用してください
- パスワードは第三者に推測されにくいものを設定してください

### 2.2 ログイン

#### 手順

1. **ログインページへ移動**
   - トップページの「ログイン」ボタンをクリック

2. **認証情報の入力**
   - **メールアドレス**: 登録したメールアドレスを入力
   - **パスワード**: 設定したパスワードを入力

3. **ログイン実行**
   - 「ログイン」ボタンをクリック
   - 認証に成功すると、マイページ（`/user/me`）に遷移します

#### ログインできない場合

- メールアドレス、パスワードが正しいか確認してください
- パスワードは大文字・小文字を区別します
- ブラウザのCookieが有効になっているか確認してください

### 2.3 ログアウト

現在のセッションを終了するには、画面右上のユーザーメニューから「ログアウト」を選択します。

## 3. トップページとナビゲーション

### 3.1 トップページの構成

トップページには以下の要素が表示されます:

- **Trippyロゴとキャッチコピー**: 「あなたの旅を計画し、共有し、実現する」
- **ログイン・新規登録ボタン**: 未ログイン時に表示
- **ユーザーメニュー**: ログイン後に表示

### 3.2 メインナビゲーション

ログイン後、以下のページにアクセスできます:

- **マイページ（`/user/me`）**: 自分のプロフィールと作成した計画を表示
- **検索ページ（`/search`）**: 公開されている計画を検索
- **計画詳細ページ（`/plans/[planId]/view`）**: 特定の計画を閲覧
- **計画編集ページ（`/plans/[planId]/edit`）**: 権限がある計画を編集

### 3.3 画面遷移の基本

- すべてのモーダルウィンドウは、画面中央に表示されます
- 「戻る」操作は、ブラウザの戻るボタンで実行できます
- 各ページには「ホームボタン」があり、クリックするとマイページに戻ります

## 4. 旅行計画の作成

### 4.1 新規計画の作成手順

#### ステップ1: 計画作成画面を開く

1. マイページ（`/user/me`）にアクセス
2. 「作成した計画」セクションの「新規作成」ボタンをクリック
3. 「計画作成モーダル」が表示されます

#### ステップ2: 基本情報の入力

計画作成モーダルで以下の情報を入力します:

| 項目                     | 必須 | 説明                     | 制限        |
| ------------------------ | ---- | ------------------------ | ----------- |
| **計画名（title）**      | ✓    | 旅行計画のタイトル       | 1〜100文字  |
| **説明（description）**  | -    | 計画の詳細説明           | 最大500文字 |
| **公開設定（isPublic）** | ✓    | 他のユーザーへの公開可否 | 公開/非公開 |

#### ステップ3: 計画の保存

- 「作成」ボタンをクリック
- 計画が作成されると、自動的に編集画面（`/plans/[planId]/edit`）に遷移します

### 4.2 計画の基本情報

作成された計画には、以下の情報が自動的に付与されます:

- **計画ID（id）**: システムが自動生成
- **作成者ID（creatorId）**: ログインユーザーのID
- **作成日時（createdAt）**: 作成時のタイムスタンプ
- **更新日時（updatedAt）**: 最終更新時のタイムスタンプ
- **お気に入り数（favorites）**: 初期値は0
- **権限（role）**: 作成者は「OWNER」権限を持つ

### 4.3 公開設定の詳細

#### 公開設定（isPublic = true）

- 検索ページに表示されます
- 他のユーザーが閲覧できます
- URLを知っていれば誰でもアクセス可能です
- お気に入りに追加できます

#### 非公開設定（isPublic = false）

- 検索ページに表示されません
- 作成者と招待されたメンバーのみ閲覧・編集可能
- URLを知っていても、権限がないユーザーはアクセスできません

## 5. タイムライン表示モード

### 5.1 タイムライン表示とは

タイムライン表示は、旅行スケジュールを**時系列**で管理するビューです。訪問する場所（プロセスノード）と移動（ムーブノード）を組み合わせて、旅程を視覚的に作成できます。

### 5.2 ノードの種類

Trippyでは、3種類のノードで旅程を構成します:

#### プロセスノード（PROCESS）

- **用途**: 滞在する場所、観光スポット、レストランなど
- **属性**:
  - 名前（name）: 場所の名前
  - 開始時刻（startTime）
  - 終了時刻（endTime）
  - 滞在時間（durationMinutes）: 分単位、最大1440分（24時間）
  - 位置情報（locationId）

#### ロケーションノード（LOCATION）

- **用途**: 地理的な場所を表す
- **属性**: プロセスノードと同様

#### ムーブノード（MOVE）

- **用途**: 移動経路を表す
- **属性**:
  - 名前（name）: 移動手段など
  - 開始時刻（startTime）
  - 終了時刻（endTime）
  - 移動時間（durationMinutes）
  - ルート情報（encodedPolyline）: Google Maps用のエンコード済みポリライン

### 5.3 ノードの追加

#### 手順

1. **追加モードの選択**
   - タイムライン画面右下の「+」ボタンをクリック
   - サブメニューが表示され、3つのノードタイプから選択できます:
     - プロセスノード
     - ロケーションノード
     - ムーブノード

2. **ノードタイプの選択**
   - 追加したいノードタイプのアイコンをクリック
   - 選択中のタイプは強調表示されます

3. **ノードの作成**
   - 「+」ボタンをクリックすると、選択したタイプのノードがタイムラインの末尾に追加されます

#### デフォルト値

- **名前**: "新しい[ノードタイプ]"
- **開始時刻**: 直前のノードの終了時刻（初回は現在時刻）
- **滞在/移動時間**: 60分

### 5.4 ノードの編集

#### 基本情報の編集

1. 編集したいノードをクリック
2. ノード詳細パネルが表示されます
3. 以下の項目を編集できます:
   - **名前**: クリックして直接編集
   - **開始時刻**: 日時ピッカーで選択
   - **終了時刻**: 日時ピッカーで選択または滞在時間から自動計算
   - **滞在/移動時間**: スライダーまたは数値入力で調整

#### 時刻の調整

- **手動調整**: 時刻フィールドをクリックして、カレンダーと時刻ピッカーから選択
- **自動調整**: 「時刻再計算」ボタンをクリックすると、すべてのノードの時刻が連続するように自動調整されます

### 5.5 ノードの削除

1. 削除したいノードを選択
2. ノード詳細パネルの「削除」ボタンをクリック
3. 確認ダイアログで「削除」を選択
4. ノードがタイムラインから削除されます

### 5.6 ノードの並び替え

- **ドラッグ&ドロップ**: ノードをドラッグして、タイムライン上で上下に移動できます（実装状況による）
- **時刻の調整**: 開始時刻を変更することで、実質的にノードの順序を変更できます

### 5.7 ルート計算機能

#### 自動ルート計算

タイムライン上の連続するノード間の移動経路を自動計算できます。

**手順:**

1. タイムライン画面左下の「ルート計算」ボタンをクリック
2. システムが以下を実行します:
   - 連続するロケーション間の最適な移動経路を計算
   - 移動時間を算出
   - ムーブノードを自動挿入または更新
   - エンコード済みポリラインを生成（マップ上に経路を表示）

#### 注意事項

- ルート計算にはGoogle Maps APIを使用します
- インターネット接続が必要です
- 大量のノードがある場合、計算に時間がかかることがあります

### 5.8 時刻再計算機能

全ノードの時刻を自動調整する機能です。

**手順:**

1. タイムライン画面左下の「時刻再計算」ボタンをクリック
2. 以下のルールで時刻が再計算されます:
   - 最初のノードの開始時刻は維持
   - 各ノードの終了時刻 = 開始時刻 + 滞在/移動時間
   - 次のノードの開始時刻 = 前のノードの終了時刻

**活用シーン:**

- ノードを追加・削除した後、時刻を整合させたい
- 滞在時間を変更した後、後続のノードの時刻を自動調整したい

## 6. アイデアスペース表示モード

### 6.1 アイデアスペースとは

アイデアスペースは、旅行の計画段階で**行きたい場所を自由に整理**するためのビューです。タイムラインとは異なり、時系列に縛られずにロケーションをカード形式で管理できます。

### 6.2 表示モードの切り替え

1. 計画編集画面の上部に「表示モード切り替えタブ」が表示されます
2. 以下の2つのタブがあります:
   - **タイムライン**: 時系列ビュー
   - **アイデアスペース**: カードビュー
3. タブをクリックすると、アニメーション付きで表示が切り替わります

### 6.3 ロケーションカードの追加

#### 手順

1. アイデアスペース画面右下の「+」ボタンをクリック
2. 新しいロケーションカードが画面に追加されます

#### ロケーションカードの内容

各ロケーションカードには以下の情報を含めることができます:

- **場所の名前**
- **位置情報**（Google Maps連携）
- **メモや説明**
- **画像**（将来実装予定）

### 6.4 ロケーションカードの編集

1. カードをクリックして選択
2. 編集パネルが表示されます
3. 名前、位置情報、説明などを編集できます

### 6.5 ロケーションカードの削除

1. 削除したいカードを選択
2. カード上の「削除」アイコンをクリック
3. 確認ダイアログで「削除」を選択

### 6.6 ロケーションカードの整理

- **ドラッグ&ドロップ**: カードを自由に並び替えられます
- **カテゴリ分け**: メモ機能を使って、カテゴリごとに整理できます（例: レストラン、観光地、ショッピングなど）

### 6.7 アイデアスペースからタイムラインへの移行

アイデアスペースで整理したロケーションは、タイムライン表示モードに切り替えることで、時系列のスケジュールに組み込むことができます。

**推奨ワークフロー:**

1. アイデアスペースで行きたい場所をリストアップ
2. タイムラインモードに切り替え
3. リストアップした場所をスケジュールに組み込む
4. ルート計算と時刻調整を実行

## 7. マップ表示機能

### 7.1 マップビューとは

マップビューは、計画内のすべてのロケーションと移動経路を**Google Maps上に視覚化**する機能です。タイムライン表示モードと連動して、右半分にマップが表示されます。

### 7.2 マップの基本操作

#### ズーム操作

- **マウスホイール**: 上下にスクロールしてズームイン/アウト
- **+/-ボタン**: マップ左下のコントロールでズーム調整

#### パン操作

- **ドラッグ**: マップをドラッグして表示範囲を移動

#### マーカーのクリック

- ロケーションマーカーをクリックすると、対応するノードがタイムラインでハイライトされます

### 7.3 マップ上の表示要素

#### ロケーションマーカー

- **プロセスノード**: 青色のマーカー
- **ロケーションノード**: 緑色のマーカー
- マーカーには番号またはアイコンが表示され、タイムライン上の順序と対応します

#### 移動経路（ポリライン）

- **ムーブノード**: 赤色の線で移動経路が表示されます
- 経路はGoogle Maps Directions APIによって計算されます

### 7.4 マップとタイムラインの連動

- **タイムライン上のノードを選択**: マップ上の対応するマーカーが強調表示されます
- **マップ上のマーカーをクリック**: タイムライン上の対応するノードがスクロール表示されます

### 7.5 マップの調整

#### リサイズ機能

- タイムラインとマップの間にある「セパレーター」をドラッグすることで、表示領域のサイズを調整できます

#### 全体表示

- マップ上の「全体表示」ボタンをクリックすると、すべてのロケーションが画面内に収まるように自動調整されます

## 8. 計画の編集と管理

### 8.1 計画情報の編集

#### 計画の基本情報を変更する

1. **編集画面へのアクセス**
   - 計画編集ページ（`/plans/[planId]/edit`）を開く
   - 計画情報セクションの「編集」アイコン（ペンマーク）をクリック

2. **編集モーダルで情報を更新**
   - **計画名**: 1〜100文字で入力
   - **説明**: 最大500文字で入力
   - **公開設定**: トグルスイッチで公開/非公開を切り替え

3. **変更の保存**
   - 「保存」ボタンをクリック
   - 成功メッセージが表示され、変更が反映されます

#### 未保存の変更がある場合

編集モーダルでは、以下の動作が実装されています:

- **未保存チェック**: 変更があるまま閉じようとすると、確認ダイアログが表示されます
- **保存中表示**: 保存処理中はローディングスピナーが表示されます

### 8.2 計画の権限管理

各計画には、以下の3つの権限レベルがあります:

| 権限       | 説明         | できること                               |
| ---------- | ------------ | ---------------------------------------- |
| **OWNER**  | 計画の作成者 | すべての操作（編集、削除、メンバー管理） |
| **MEMBER** | 編集メンバー | 計画の閲覧と編集（削除はできない）       |
| **VIEWER** | 閲覧者       | 計画の閲覧のみ                           |

### 8.3 編集モードと閲覧モード

#### 編集モード（`/plans/[planId]/edit`）

- **権限**: OWNERまたはMEMBER
- **機能**: すべての編集操作が可能
- **UI**: 「+」ボタン、編集アイコン、削除ボタンが表示されます

#### 閲覧モード（`/plans/[planId]/view`）

- **権限**: VIEWERまたは公開計画の場合はすべてのユーザー
- **機能**: 計画の内容を閲覧のみ
- **UI**: 編集用のボタンは表示されません

### 8.4 計画の削除

**注意**: 計画を削除すると、すべてのノード、ロケーション、メンバー情報が完全に削除されます。この操作は元に戻せません。

#### 手順

1. 計画編集ページを開く
2. クイックメニュー（右上の三点リーダー）をクリック
3. 「計画を削除」を選択
4. 確認ダイアログで「削除」を選択
5. 計画が削除され、マイページに戻ります

## 9. 計画の検索と閲覧

### 9.1 検索ページの概要

検索ページ（`/search`）では、Trippyに登録されている**公開計画**を探すことができます。

### 9.2 検索方法

#### キーワード検索

1. 検索ページ上部の検索フィールドにキーワードを入力
2. 以下の項目が検索対象になります:
   - 計画名
   - 計画の説明
   - 作成者のユーザー名

3. Enterキーを押すか、検索ボタンをクリック
4. マッチした計画が表示されます

#### フィルタ検索（実装状況による）

以下のフィルタオプションが利用できます:

- **カテゴリ**: 旅行の種類（観光、ビジネス、グルメなど）
- **期間**: 旅行の日数
- **地域**: 目的地の地域

### 9.3 検索結果の表示

検索結果は2つのタブに分かれています:

#### 人気タブ（Popular）

- **並び順**: お気に入り数の多い順
- **用途**: 人気のある計画を参考にしたい時

#### 新着タブ（New）

- **並び順**: 作成日時の新しい順
- **用途**: 最新の計画をチェックしたい時

### 9.4 計画カードの情報

各計画は「計画カード」として表示され、以下の情報が含まれます:

- **計画名**
- **説明**: 最初の数行のプレビュー
- **作成者情報**: ユーザー名とアイコン
- **お気に入り数**: ❤️アイコンと数値
- **公開状態**: 公開中のバッジ
- **サムネイル画像**（将来実装予定）

### 9.5 計画の閲覧

1. 興味のある計画カードをクリック
2. 計画詳細ページ（`/plans/[planId]/view`）に遷移
3. 計画の内容を閲覧できます（編集権限がある場合は編集も可能）

### 9.6 検索のヒント

- **具体的なキーワード**: 「東京 3日間」「京都 神社巡り」など具体的なキーワードを使用
- **複数キーワード**: スペース区切りで複数のキーワードを入力（AND検索）
- **ユーザー名検索**: 特定のユーザーの計画を探す場合は、ユーザー名で検索

## 10. お気に入り機能

### 10.1 お気に入り（いいね）とは

お気に入り機能は、気に入った計画に「❤️いいね」をつけることで、後から簡単にアクセスできるようにする機能です。

### 10.2 計画にいいねをつける

#### 手順

1. いいねをつけたい計画を開く（閲覧モードまたは編集モード）
2. 計画情報セクションの「❤️いいね」ボタンをクリック
3. ボタンが赤色に変わり、いいね数が1増加します

#### いいねの取り消し

1. すでにいいね済みの計画を開く
2. 赤色の「❤️いいね」ボタンを再度クリック
3. いいねが取り消され、ボタンが灰色に戻ります

### 10.3 お気に入りの計画を確認する

#### マイページから確認

1. マイページ（`/user/me`）にアクセス
2. 「お気に入りの計画」セクションにスクロール
3. いいねをつけたすべての計画が表示されます

#### 他のユーザーのお気に入りを見る

1. 他のユーザーのプロフィールページ（`/user/[userId]`）にアクセス
2. 「お気に入りの計画」セクションを確認
3. そのユーザーがいいねをつけた計画が表示されます

### 10.4 お気に入り数の活用

- **人気の指標**: お気に入り数が多い計画は、多くのユーザーから支持されています
- **検索結果の並び順**: 「人気」タブでは、お気に入り数順に計画が表示されます
- **モチベーション**: 自分の計画がいいねされると、作成者のモチベーションが向上します

## 12. 共同編集とメンバー管理

### 12.1 共同編集機能とは

共同編集機能を使用すると、複数のユーザーで1つの旅行計画を共同で作成・編集できます。家族旅行や友人との旅行計画を、全員で協力して作成する際に便利です。

### 12.2 メンバーの招待

#### 手順

1. **計画編集ページを開く**
   - 招待したい計画の編集ページ（`/plans/[planId]/edit`）にアクセス

2. **メンバー管理パネルを開く**
   - 画面右側または上部の「メンバー」アイコンをクリック
   - メンバー一覧とメンバー追加フォームが表示されます

3. **メンバーを追加**
   - 招待したいユーザーのメールアドレスまたはユーザー名を入力
   - 権限レベルを選択:
     - **MEMBER**: 編集権限を付与
     - **VIEWER**: 閲覧のみの権限
   - 「招待」ボタンをクリック

4. **招待の送信**
   - 招待されたユーザーに通知が送信されます（実装状況による）
   - ユーザーが招待を承認すると、メンバーリストに追加されます

### 12.3 メンバーの管理

#### 権限の変更

1. メンバー一覧から権限を変更したいメンバーを選択
2. ドロップダウンメニューから新しい権限レベルを選択
3. 「更新」ボタンをクリック

#### メンバーの削除

1. メンバー一覧から削除したいメンバーを選択
2. 「削除」ボタンをクリック
3. 確認ダイアログで「削除」を選択
4. メンバーが削除され、その計画へのアクセス権が取り消されます

**注意**: OWNER権限を持つユーザーは削除できません。

### 12.4 リアルタイム共同編集（実装状況による）

Trippyは、WebSocketまたはポーリングによるリアルタイム同期をサポートしています（`PlanCollaborator`コンポーネント）。

#### 動作

- 複数のユーザーが同時に編集している場合、変更がリアルタイムで反映されます
- 他のユーザーが編集中の箇所がハイライト表示されます
- コンフリクト（衝突）が発生した場合、最後に保存した変更が優先されます

#### 推奨事項

- 大規模な変更を行う前に、他のメンバーに連絡することを推奨します
- 定期的に保存して、変更内容を同期してください

作成した旅行計画を、外部のアプリケーションやサービスで利用するために、データをエクスポートできます。

### 13.4 エクスポートデータの活用

- 印刷して持ち歩く

## 14. よくある質問（FAQ）

### Q1. 計画は何個まで作成できますか？

A. 現時点では、作成できる計画の数に制限はありません。ただし、将来的に有料プランで制限が設けられる可能性があります。

### Q2. 作成した計画は削除できますか？

A. はい、OWNER権限を持つユーザーは、いつでも計画を削除できます。ただし、削除した計画は復元できませんので、ご注意ください。

### Q3. 非公開にした計画は本当に他の人に見えませんか？

A. はい、非公開設定（`isPublic = false`）にした計画は、作成者と招待されたメンバー以外は閲覧できません。検索結果にも表示されません。

### Q4. 無料で利用できますか？

A. はい、現時点ではTrippyはすべての機能を無料で提供しています。

### Q5. スマートフォンでも使えますか？

A. Trippyはレスポンシブデザインを採用していますが、最適な体験はデスクトップまたはタブレットで得られます。スマートフォンでの利用も可能ですが、一部の機能は制限される場合があります。

### Q6. Google Maps APIキーが必要ですか？

A. いいえ、ユーザーがAPIキーを用意する必要はありません。TrippyのシステムでGoogle Maps APIを管理しています。

### Q7. オフラインでも使えますか？

A. 現時点では、Trippyはオンライン接続が必要です。オフライン対応は将来的な機能として検討中です。

### Q8. 計画をコピーできますか？

A. 現時点では、計画のコピー機能は実装されていません。将来的なアップデートで追加予定です。

### Q9. 他のユーザーの計画を編集できますか？

A. できません。他のユーザーの計画を編集するには、そのユーザーからMEMBER権限で招待される必要があります。

### Q10. パスワードを忘れた場合はどうすればいいですか？

A. ログインページの「パスワードを忘れた方」リンクから、パスワードリセット手続きを行ってください（実装状況による）。

## 15. トラブルシューティング

### 15.1 ログインできない

#### 症状

- メールアドレスとパスワードを入力してもログインできない

#### 対処法

1. メールアドレスとパスワードが正しいか確認
2. パスワードの大文字・小文字を確認
3. ブラウザのCookieが有効になっているか確認
4. 別のブラウザで試す
5. キャッシュとCookieをクリアして再試行

### 15.2 計画が保存されない

#### 症状

- 編集内容が保存されない、またはエラーメッセージが表示される

#### 対処法

1. インターネット接続を確認
2. ブラウザをリロード（F5キー）
3. 入力内容が文字数制限を超えていないか確認
   - 計画名: 1〜100文字
   - 説明: 最大500文字
   - ノード名: 1〜100文字
4. ブラウザのコンソールでエラーメッセージを確認

### 15.3 マップが表示されない

#### 症状

- マップ領域が灰色または空白で、地図が表示されない

#### 対処法

1. ページをリロード（F5キー）
2. ブラウザの設定で位置情報のアクセスが許可されているか確認
3. 広告ブロッカーやトラッキング防止機能を一時的に無効化
4. 別のブラウザで試す

### 15.4 ルート計算が失敗する

#### 症状

- 「ルート計算」ボタンをクリックしても、経路が表示されない

#### 対処法

1. すべてのノードに有効な位置情報が設定されているか確認
2. ノードが2つ以上存在するか確認
3. インターネット接続を確認
4. しばらく待ってから再試行（APIの利用制限の可能性）

### 15.5 画面が真っ白になる

#### 症状

- 特定のページにアクセスすると、画面が真っ白になる

#### 対処法

1. ブラウザをリロード（F5キー）
2. ブラウザのコンソールでJavaScriptエラーを確認
3. キャッシュをクリア
4. 別のブラウザで試す
5. それでも解決しない場合は、サポートに問い合わせ

### 15.6 メンバーを追加できない

#### 症状

- メンバー招待が失敗する、またはエラーメッセージが表示される

#### 対処法

1. 招待するユーザーのメールアドレスまたはユーザー名が正しいか確認
2. 自分がOWNER権限を持っているか確認
3. すでにメンバーに追加されていないか確認
4. インターネット接続を確認

### 15.7 計画が見つからない

#### 症状

- 作成したはずの計画がマイページに表示されない

#### 対処法

1. ページをリロード
2. ログアウトして再ログイン
3. 検索ページで計画名を検索
4. URLを直接入力してアクセス（`/plans/[planId]/view`）

### 15.8 エクスポートが動作しない

#### 症状

- エクスポートボタンをクリックしても、ファイルがダウンロードされない

#### 対処法

1. ブラウザのダウンロード設定を確認
2. ポップアップブロッカーを無効化
3. 別のフォーマットで試す
4. ブラウザをリロードして再試行

### 15.9 時刻がずれる

#### 症状

- ノードの時刻が意図したものとずれる

#### 対処法

1. 「時刻再計算」ボタンをクリック
2. 各ノードの開始時刻と滞在時間を確認
3. ブラウザのタイムゾーン設定を確認

### 15.10 サポートへの問い合わせ

上記の対処法で解決しない場合は、以下の情報を含めてサポートにお問い合わせください:

- **問題の詳細**: 何が起きたか、何をしようとしていたか
- **エラーメッセージ**: 表示されたエラーメッセージの全文
- **環境情報**:
  - 使用しているOS（Windows、macOS、iOS、Androidなど）
  - 使用しているブラウザとバージョン
  - 画面解像度
- **再現手順**: 問題が再現する手順
- **スクリーンショット**: 可能であれば、問題が発生している画面のスクリーンショット
